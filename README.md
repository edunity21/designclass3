# 음악으로 먹고사는 사람들

유정준 선생님(순천승평중학교)의 `단원수업설계_음악산업탐구_유정준_AI반영.hwtx`를 바탕으로 만든 한국어 반응형 웹 페이지입니다.

## 바로 열기

`index.html`을 브라우저에서 엽니다. 별도 설치나 빌드 없이 사용할 수 있습니다. 인터넷 글꼴, 이미지, 외부 스크립트에 의존하지 않습니다.

## GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. **Add file → Upload files**에서 이 폴더 안의 `index.html`, `styles.css`, `app.js`, `README.md`, `.nojekyll`을 저장소 최상위에 올립니다. ZIP 자체를 올리는 것이 아니라 압축을 푼 파일을 올리세요. `.nojekyll`이 보이지 않아도 이 사이트의 일반 파일은 사용할 수 있습니다.
3. 변경 사항을 저장한 뒤 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**, `main` 브랜치, `/(root)` 폴더를 선택하고 저장합니다.
5. 배포가 완료되면 Pages 설정 화면에 표시되는 주소를 엽니다. 보통 `https://사용자이름.github.io/저장소이름/` 형식입니다.

계정이나 저장소 조건에 따라 Pages 제공 여부와 화면은 다를 수 있습니다. 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 포함 기능

- 단원 개요, 성취기준, 4차시 수업 흐름 및 2차시 45분 상세 설계
- 12개 음악 산업 분야 검색, 관련 직업 예시, 탐구 질문
- AI 답 교차 확인과 학생의 직접 수행 범위
- 산업 조사 40점 / 음악의 활용 가치 30점 / 발표 수행 30점 루브릭
- 9문항 활동지, 현재 브라우저 자동 저장, UTF-8 텍스트 내보내기
- 활동지 인쇄·PDF 저장, 60초 발표 연습 타이머
- 모바일 레이아웃, 키보드 차시 탐색, 움직임 감소 설정 대응

## 실제 수업 운영 범위

이 페이지는 정적 안내·연습 사이트입니다. 브라우저 저장은 기기나 브라우저 사이에서 공유되지 않으며, 기록 삭제 시 사라질 수 있습니다. 파일 내보내기로 결과를 보관하세요. 공용 기기에서는 개인정보를 입력하지 마세요.

원문에 기획된 학교 계정 로그인, 수업 비밀번호, 입장·제출 시간 통제, 서버 자동 저장·제출 시각 기록, 교사 제출 현황, 영상 녹화·드라이브 수합, 동료평가 수집은 포함되어 있지 않습니다. 수업 중 수행평가 제출은 교사가 지정한 별도 절차를 사용해야 합니다. GitHub Pages만으로 이러한 서버 기능을 제공할 수는 없습니다.

## 내용과 수정

- `index.html`: 단원 설명, 수업 설계, 평가 기준, 운영 안내
- `app.js`: 차시별 내용, 12개 분야, 활동지 문항, 저장·검색·타이머
- `styles.css`: 색상, 화면 크기별 배치, 인쇄 스타일

원문의 빈 서식 안내와 작성용 메모는 제외하고 교육 내용을 재구성했습니다. 12개 분야 이름·수업 흐름·평가 점수는 원문을 따릅니다. 직업 예시와 카드별 탐구 질문은 웹 탐색을 위해 덧붙였고, 활동지 문장은 원문에서 설명한 1~9번의 취지를 바탕으로 재구성했습니다. 원본 HWTX와 학생 데이터는 업로드 묶음에 포함하지 않습니다.

원문 내용에 관한 저작권은 해당 권리자에게 있으며, 공개 배포 전 공개 범위를 확인하세요. 별도 오픈소스 라이선스는 임의로 부여하지 않았습니다.
